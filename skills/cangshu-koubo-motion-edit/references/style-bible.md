# 风格总纲：真人 ↔ 图形交替的口播剪辑

依据：对同类知识口播爆款（真人段 ↔ 图形段交替的剪法，下称"参考片"）的逐帧实测（光流、特征点测镜头、直线汇聚反推 3D 角度、逐条标注 695 个动效、音频分频段对齐），加上 v9–v14 十几轮返工里暴露出来的问题。原始拆解和测量报告不随 skill 分发，按本文件的结论做。

## 1. 三条原则

1. **讲者说一句，画面对这句做出反应。** 真人段每 3–6 秒一次视觉变化，图形段约每 0.6–1.5 秒一个动作；动词出口那一下就是动作发生的那一下。
2. **图形段是"一个主角演一条链"，不是 PPT 翻页。** 同一个东西一路变形（水箱注水→打转→挤满→升塔），新东西从旧东西身上长出来，元素之间一边变、另一边跟着变。
3. **克制出高级。** 镜头停得住、音效少而轻、留白多、强调色不超过两个；不穿模、不越界。

## 2. 节奏数字

| 指标 | 对标实测 | 本 skill 的目标 |
|---|---|---|
| 图形占比 | 51–67%（逐字稿那条 64%） | 45–65%；60 秒以内的短视频可以降到 30% |
| 换世界 | 平均 10–15 秒一次；真人段中位 5.8 秒，图形段中位 13.8 秒 | 真人段 3–10 秒，图形段 ≤16 秒 |
| 语速 | 364–411 字/分钟 | 粗剪把超过约 0.35 秒的停顿剪掉，只留前后各 0.08 秒气口 |
| 剪辑点 | 多数卡在句子边界 | 换世界、镜头运动都落在句首 |
| 图形段运动 | 81–83% 的帧在动，最长静止 ≤0.7 秒，约 0.6–0.9 秒一个事件 | 进场 0.6 秒内有东西，之后每 ≤1.5 秒一个事件 |
| 图形段互动 | 44% 的动效和别的元素有作用关系，约每分钟 52 次 | 同量级；每段 ≥3 条状态联动链 |
| 构图 | 人水平居中，脸高约 1/5 画面 | 3:4 里脸中心在画面 38% 高度 |

## 3. 真人段（A）

所有叠层避开脸。信息放左上，用毛玻璃材质；顶部常驻进度条。

| 叠层 | 什么时候用 | 做法 |
|---|---|---|
| 进度导航 `chapters` | 默认都加，短视频 3 段 | 顶部分段进度条全片常驻，当前段随时间填满；每章开头左上弹出导航卡（圆形线图标 + 序号中文 + 英文小字，当前项点亮、讲完打勾），停约 2.6 秒后每行飞进进度条对应那格。这段左上要出别的卡时，导航卡先收完（让位后不到 0.6 秒就不弹） |
| 数据卡 `metric` | 一个关键数字 | 左上毛玻璃卡：标题 + 数字滚动 + 20 格分段条 + 注释小字；个人估计写"个人判断" |
| 胶囊 `tag` / `pill` | **默认不用**（角落小字胶囊显得 AI 味重） | 字段还在，只在用户点名要时用；批注、便利贴、新闻条、花字、不写字的动效提示也都默认不用 |
| 前景大字 `bigText` | 结论、反问、章节关键词 | 逐字从遮罩里升起、去模糊，下面一条细线 + 小标签（side / en）；带深色描边 + 投影，落在白墙上也看得清 |
| 身后大字·顶边 `topWord` | **默认用这个**：两三个字的重点词（AI、暴利、崩坏、代差），偶尔用（4–5 分钟的片子三四次），每次 1.5–3 秒，落在说出这个词的那一下前后 | 白字黑描边、立体厚度 + 钨钢亮面（`look: "steel"`），顶着进度条下沿、第一个字贴左、最后一个字贴右，字高约画面四成，被头挡一点没关系。至少停 1.5 秒，短了挪前后段边界（一闪而过观众看不清）。开头的大字可以在下一句缩小飞进左上信息框当角标（`fly`） |
| 身后大字 `bigText behind` | 一句较长的字要放身后时 | 抠像压在字上、头挡住一角；`fit_bigtext.py` 逐字算遮挡（≤35%）并保证不顶进进度条，挡太多就放到人前面 |
| 左上信息框 `infoBox` | 偶尔，列几个要点（这期讲什么、五个活、翻译 / 画图 / PPT 逐个加） | 英文渐变大写 + 中文标题的玻璃头，下面一条条带图标的玻璃胶囊，每条卡着口播出；音效有时加有时不加（`sfx` all / head / none）。和开头大字同时出时，大字先飞成信息框的角标再出条目，免得撞 |
| 贴头关键词 `sideWords` | 两个并列词、因果对（A ≠ B、A → B） | 先左后右，模糊 → 清晰；同样带深色描边 |
| 结论便签 `sticker` | 一段论证的最后一句 | 玻璃便签从下往上翻起来立住 |
| 推拉 | 一直在 | 默认交替慢推慢拉（每秒约 1.5%），相邻实拍段首尾相接；重音句用一次缓推（`punch`，0.6 秒），落在句首；相邻两段 `zoom` 不同时 0.7 秒缓过去。不要跳切式的瞬间推近（太突然；参考片的实拍段一直在慢推慢拉） |
| 实拍段长度 | 每段 | 不短于约 2.2 秒：实拍只露一两秒就又切走，观众会觉得晃眼；不够就把前后图形段的边界挪一挪 |

颜色语义固定：青 = 我的/对的，红 = AI 味/错/被绑，金 = 重点/成果，蓝 = 数据/知识，灰 = 旧的/别人的。状态翻转只换颜色。

## 4. 什么时候进图形、什么时候回真人

- 进图形：开始讲机制、举例、给数据、做对比的那句。
- 回真人：表态、下结论、转折词（"但你别忘了""说白了""所以"）那句，停 3–7 秒喘口气，用大字或贴头字钉住关键词。
- 一段图形默认 ≤16 秒，超出 1 秒以内可以不拆；更长就在转折词那里插一段真人拆成两段。只有台词一口气讲同一个机制、中间没有表态句时才允许到 20 秒左右。
- 跨世界接力：真人段左上的数据卡在图形段开头直接变形成主角（95% 数据卡 → 需求单），或者真人段的前景大字、贴头字飞进图形段变成主角身上的标签。（样例 stock1 用的是真人段胶囊飞进来，胶囊现在默认不用，换成大字。）

## 5. 图形段（B）：一个主角、一条链、状态联动

**主角和链条**：先写这段的主角（骨架）和它按台词经历的几个状态，例如"一个水箱：注水 → 阀门关 → 打转 → 套机甲挤满 → 升塔 → 一人登顶"、"一张需求单：点按钮 → 倒成浅盘 → 被机器人收走 → 复制成两份 → 上天平"。新东西从旧东西身上长出来、离场时并进别的东西；镜头在主角周围推拉，不在几个孤立道具之间甩。

**状态联动（最核心）**：两个元素用一根线或同一个位置连起来，一边变、另一边跟着变。对标例子：终端里"删"的字数往下滚、旁边稿子里红字同步消失；列表每加一行，同心圆扩一圈，圈扫到的节点变色；拧开关 → 管线标签换字 → 脑子里液面上涨。

其余连法：
1. 一个骨架贯穿 10–20 秒（文档、时间轴、窗口），别的东西都挂在它身上。
2. 出生有来源：小胶囊从母体边缘冒出来再展开；进度条走完从末端长出报告。
3. 讲完收回去：标签飞回文档，文档被吸进提词器、提词器接着滚它的字。
4. 因果互动：敲键盘 → 文档出字、字数跳；文件飞进知识库 → 篇数涨。
5. 连线是活的：虚线端点跟着目标跳，光点沿线流。
6. 颜色当纽带：同一含义同一颜色，从标签一路带到结果。
7. 前后照应：上一段的道具下一段再出现；讲完的卡缩成路线图节点，切回真人变成章节导航。
8. 旧的压暗、不删除：转折句一来整体变灰留作背景，新结构从里面长出来。

边界（逐条标注后的结论，别矫枉过正）：对标并非每个元素都有来源——新元素约三成从已有元素长出、两成挂在某个元素上出现、四成多原地出现；拉开差距的是互相作用的密度和几条清楚的联动链。镜头从不"移过去露出摆好的东西"，而是先腾出空地，新内容从已有元素里长进去。

**信息量**：任何一个元素停留不超过 5–7 秒，就要有新元素加进来或者发生变换，除非这个元素本身在给大量信息（例：3–9 秒只有一个钟在转 → 不行）。检查：渲预览后逐段量画面变化（去掉字幕带和进度条），找超过 4 秒没有新事件的空档补东西。

**三层运动**：底层字墙一直在动（相邻行反向、一快一慢）；中层道具自带循环（光点流、液面波纹、滚字），任何道具静止超过 1 秒都挂一个；上层事件每 0.6–1.5 秒一个。全静止只用来做"爆发前的空"，后面必接大动作。

**演示占主位，数据卡做旁注**：机制用道具演出来（占画面 45–70% 高）；数据卡从道具边上长出来补证据，讲完缩回去。数据卡自己也要动（数字滚、条要长）。

**立体倾斜只救平的画面**：只有一张卡、一行字、一个印章、周围没道具在动时才用 `Tilt`（从 rotateX 50–70° 翻进来，落到 5–8° 残留角，±1.5° 慢摆）；道具本身在演、或已有三个以上元素在动时不加；同一画面最多一个倾斜元素。

## 6. 图形段镜头：停得住 + 3D 画布

| 指标 | 对标 | 规则 |
|---|---|---|
| 镜头多久动一次 | 3.8 秒 | 只在句子交界处动，平均 3.5–4 秒一次 |
| 每次停留 | 中位 2.1 秒，三成停 3 秒以上 | ≥2 秒，最短 1.4 秒；停的时候完全不动，靠元素动作撑住 |
| 一次运动 | 0.8 秒，七成以推拉为主，一次 20–35% | 0.6–0.9 秒，推拉 10–35% 带一点平移 |
| 速度曲线 | 对称缓入缓出 | `tw` 默认 smootherstep；推拉走对数插值 |
| 画布 3D | 每段 yaw 从一侧转到另一侧约 15°、pitch 约 5°，平面内不旋转 | `Camera3D` + `orbitAt(t, MOVES)`（默认值已按实测标定，别改符号） |

- 3D 角度像一台"转头看画板"的摄像机：只在镜头运动前后转，比机位移动拖得长（运动前约 0.6 秒开始，持续约 2.4 秒），停留时不转。
- 转场 = 镜头运动 + 元素变形同时发生（文档一边缩小一边飞进提词器、镜头同时拉远），不要先动镜头再动元素。
- 重音用元素动作或一下轻震（`wobble`），不用镜头猛推；甩镜头用定向运动模糊（`camVel`）。

**段内多画布**（学参考片里一段多块内容在画布上横移的做法）：一段 B-roll 的信息一屏放不下时，把几块内容摆在画布不同位置，镜头按台词在块之间横移、竖移，上一块出画、下一块进画，需要时最后拉远一起看。规则：
- 只在一段 B-roll 内部走，不在不同 B-roll 之间翻页（翻页式运镜不带信息）。
- 不为运镜而运镜：一屏装得下就不拆（每块只展示三成、其余是空白时，运镜没有意义）。要拆就挪半屏左右（约 500px），每屏都填满、旁边那块露半截；不要甩一整屏让每块只剩三成内容。
- 块之间要有东西带着镜头走：同一张稿子、价签、手机、纸带从这块飞到那块，镜头跟着，讲的是同一件事。
- 推镜 0.8–0.9 秒、`Stage` 加 `blurK={0.3}`：默认动态模糊太重，推的那一下整屏糊成一片，看不清元素怎么出画进画。
- 拉回、拉远时检查有没有字被画框切成半截（「6,000 字/天」只剩「/天」），有就挪到全进或全出。
- 例：某条样片里翻译、网文挪半屏，写代码左右两块（两块都满）；画图、PPT 一屏放得下就没拆。代码见 `scenes/custom/real.tsx` 的 `Block`。

## 7. 高级感（画风）

**先定画风**（SKILL 第 3.5 步）。两条路：`lux.tsx` 白卡精致（色板固定，不参与主题），或用 `toon.tsx` 写场景、`meta.style` 在 9 套主题里换（同一份场景代码换个字段就换画风，风格样片 `style_reel.py` 只对这条路有效）：

| `meta.style` | 名字 | 样子 | 适合 |
|---|---|---|---|
| —（用 `lux.tsx` 写场景） | 白卡精致 | 白卡细线柔和投影，下面的规则 | 偏商务、发布会感 |
| `toon` | 动画片（米黄纸） | 暖棕描边、大头小人有表情会眨眼、线条手抖、米黄纸底 | 亲切、生活化 |
| `white` | 白卡极简 | 冷白网格底、细线、柔和悬浮投影（toon 工具画的白卡，不是 lux.tsx） | 干净专业 |
| `chalk` | 黑板粉笔 | 墨绿黑板、粉笔线、手抖更重 | 讲课感 |
| `dark` | 深色科普 | 深蓝星空底、亮色扁平物件带微光，默认开品牌字墙 | 社会观察、科普 |
| `news` | 报纸拼贴 | 网点底纹、粗黑线、黑色硬投影 | 新闻、时事 |
| `blue` | 蓝图工程 | 蓝底白网格、白细线、描边标签 | 拆机制、讲原理 |
| `neon` | 霓虹赛博 | 近黑底、透视网格地面、青紫霓虹光 | 科技、AI |
| `water` | 水彩手账 | 米白水彩纸、晕染颤动边 | 温柔、情绪向 |
| `wall` | 实拍背景墙 | 取自你实拍背景墙颜色的主题（颜色在 toon.tsx 的主题表里改）：渐变 + 细颗粒，细边框、柔和长投影、胶囊标签（产品界面手法），不手抖；配 `wall: true` 字墙 | 和实拍接得上：拆景时空墙淡成这张底不跳色。按你的墙色改好后适合当默认 |

**推荐默认组合**（一个号定下来以后直接照用，不必每条都出风格样片）：
- 底：`style: "wall"` + 品牌字墙（`meta.brand` 填你自己的品牌名，中文加英文效果好，如「品牌名 BRAND」）。换风格时只换元素和动画，底色和字墙不动（底色和滚动字墙是一个号的识别度，变的只是元素和动画风格）。
- 人物：角色精灵图（可选）：使用者自备透明 PNG 放进 `public/ipq/` 并登记尺寸到 `scenes/custom/ipq.json`，开 `meta.qkid: true`；不配就用 `toon.tsx` 里代码画的小人 `Kid`。配角用同画风。**小人是配角不是主体**：动效不围着小人设计，多数时候只露头（`crop: "head"`）或半身（`crop: "bust"`），偶尔全身。要新动作就自备新的精灵图（一张图里排了多个动作的绿底动作表可以用 `scripts/split_sheet.py` 切开），同样放进 `public/ipq/` 并登记 `ipq.json`。
- 物件也用代码画（`scenes/custom/objs.tsx` 的 `Obj`：汉堡、奶茶、饼、鱼、沙发、日历、小票……平涂 + 一层明暗，缺的照样往里加），不用生图：写实 3D 物件和小人、底色不搭。
- 程序窗口（标题栏 + 三个小圆点）只在内容真是程序时用（聊天窗、代码窗），偶尔用；单独一根进度条、一排日历、一张清单都不塞窗口，进度条直接画在底上，做粗做大。
- 对比条别堆重复：一根条要细分时当场一分为二，不要一上来摆四根。
- 元素：用代码画（生成的图片元素动不起来，画风也对不上），保留原来"主角 + 链条 + 联动"的逻辑，吸收产品界面的手法：细边框（`T.line`）、柔和长投影（`T.shadow`）、定价卡、数据卡、任务卡、胶囊标签。现成的在 `scenes/custom/ep.tsx`（Doc 窗口、PriceTag 定价卡、Ledger 数据卡、Order 任务卡、Chip、YearDial、Stall、Desk、Clock）。不用卡通粗描边、硬投影、手绘抖动。
- 多页面运镜：见第 6 节「段内多画布」，一屏放不下才用。
- 真实素材：图形段里可以插真图，讲台词里那件事（游戏 CG、排完版的幻灯片、小程序截图、中英对照稿、网文页、短剧剧照）。只用使用者自己提供的、有授权的图片（截图、自己做的图、自己用任意工具生成的图），不去网上找图；放 `public/real/`，上屏用 `real.tsx` 的 `RealImg` / `RevealImg`，是 AI 生成的就挂「AI 生成」角标（`AiTag`）。**只用图，不用实拍视频**（实拍素材视频出戏、不符合画风，也表达不出要点）。图里的字也要查（抽不出来，人工逐张看）：交给你项目里的合规 / 文字自查 skill（可选；没有就交给用户自己查）。写实 AI 人像发布时要勾平台的 AI 生成声明。
- 不推荐的：3D 潮玩手办风（元素全是生成的图片，动不起来）、大头卡通小人（太卡通）、换风格时连底色一起换。

主题只换颜色、描边粗细、手抖、背景和整体质感；场景里的颜色一律取 `T.*`，不写死（写死的浅色在深色主题里会突兀，写死的深字会看不见）。**品牌字墙**（`meta.wall`）：图形段背后一行行品牌字，相邻行反向、一快一慢，实心字和空心描边字交替，镜头一动整面墙被推一下（像参考片那样），切回真人段消失。

下面是白卡（`lux.tsx`）的规则，动画片主题照同样的克制原则：
- 克制：元素占画面三到五成，留白多；一个画面最多两个强调色（`L.blue #2F6BFF` 数据、`L.gold #F5A623` 重点、`L.red #F0464B` 错/警告、`L.cyan #12B3C9` 我的/对的），其余是白和灰（`L.ink #0F1A2A` 字）。
- 同一套材质：白卡 + 1px 细边 + 柔和长投影；道具有渐变和高光（玻璃水箱、金属塔、白色机器人），不用粗黑描边的卡通线稿。
- 字分三层：大字或大数字 / 中文标签 / 极小英文或出处（等宽、全大写、拉开字距）。中文字重 600，数字 700。标签用 `Chip`（中文 + 极小英文）。
- 光和景深：浅色径向渐变背景（中间亮四周暗），字墙轻微模糊，四角压一点暗角；真人画面也压暗角。
- 字号：中文 ≥22px；英文小字和出处这一层可以 12–16px（只作装饰和背书，看不清也不影响理解）。字幕居中、字幕框顶边 y≈1150、54px、单行 ≤14 字。苹方、Avenir 是系统字体，接商单前换有商用授权的字体（改 `theme.ts` 的 F）。

## 8. 动效手感和卡点

- 所有元素按绝对时间算（同一帧永远同一个画面）；落位用 `out5` / `outBack`，飞行用缓入缓出，掉落用加速。
- 常用时长：弹出用 `popIn`（默认 0.35 秒、过冲约 1.15）；卡片进场 0.3 秒；数字滚动 0.9–1.2 秒先快后慢；盖章 1.8→1 用 3 帧；卡片变形 0.4–0.6 秒。
- 卡点：动词误差 ≤0.1 秒；名词提前 0.3–1 秒；数字提前 0.4 秒起跑；✓/✕ 比所属选项晚 5–10 帧；计数时长 = 整句时长；口播一列举，画面按同样节拍落子；转折词动镜头或换世界。
- 第二次出现的东西快放，观众看懂的不浪费时间。

## 9. 转场

**进图形（有抠像时，学参考片：背景先变，人最后动）**，两种基础切镜不混用：

| 名字 | 什么时候用 | 做法 |
|---|---|---|
| 拆景 `enter: "split"` | 多数时候，强切镜；背景两侧没有明显物件时不要用，改用淡出 | 把切镜那一帧拆成背景墙 + 左右两侧物件三层：左侧物件往左、右侧物件往右滑出画 → 空墙淡成图形底（字墙）→ 人最后动：抠出来的半身缩到右下角（`host: "corner"`），或原地淡出（`none`，不往下走，往下走看着太突兀）。进场那一下配一声 whoosh |
| 淡出 `enter: "fade"` | 不需要强切镜、节奏缓一点的段 | 实拍整个淡出 → 人原地晚一点淡出（不动）→ B-roll 某处淡入圆形小镜头（`host: "bubble"`） |
| 变身 `host: "morph"` | 这段 B-roll 开头是小人时；只在配了角色精灵图（`meta.qkid`）时可用 | 真人缩到小人头上变成小人；和拆景叠用（先滑走两侧物件再变身）。四种做法（缩放溶解 / 圆形光圈 / 照片贴纸 / 一阵烟）酌情取用，一条片子一两次。退场统一是实拍柔和叠化（段尾最后 0.8 秒，略虚略大 → 清晰原位），不把脸从小人头放大到满屏（会突然跳出一个大头），也不先让两侧物件滑回来（要提前 2 秒开始，盖住最后的内容） |

- 拆景以后只能配抠出来的半身，不能配圆球（圆里是带背景的原画面，等于两侧物件又回来了）。
- 圆球、角落半身可以按 `hostPath` 跟着动效挪位置，但别挡住内容。
- 手写场景的第一个元素从 `contentStart(seg)` 起出（拆景 1.0 秒、淡出 0.75 秒、变身 1.2 秒），别在切镜动画里出东西。
- `FACE` / `CORNER` / `BUB`（Film.tsx 顶部）和 `split_plates.py` 是按"背景左侧有前景物件、右侧有物件、人居中"的机位调的，这些参数要按你自己的拍摄背景调：先抽帧看，拆景拆不干净、或背景两侧没有明显物件，就用 fade。

**回真人：默认硬切**（`exit` 不写）。动效是为内容服务的：人回中间、两侧物件滑回、实拍淡回这些退场动画都会盖住最后一句的内容，还会闪一下。变身段默认是实拍叠化上来（见上表）。最后一个要讲的元素要在退场开始前露够 1 秒以上，不够就把它提前到那句话一出口。

| 方向 | 做法 |
|---|---|
| A→B（没抠像） | 0.2 秒叠化，新画面 1.1→1.0；真人段的卡片可以直接变形成图形段主角 |
| B→A | 硬切；没抠像时 0.2 秒叠化，真人画面 1.08→1 落版 |
| A→A | 推拉跳切，不加过渡 |
| B 内 | 不翻页：靠主角变形 + 镜头推拉 |
| B→B | 两个图形段直接相连时，模板是上一段最后 0.3 秒淡出、下一段直接切入（要叠化得改 Film.tsx）；最好在中间插一句真人 |

模板里还有换底（`swap`）、装进手机（`swallow`），没在成片里验证过，要用先单独出预览看。

## 10. 声音

**音效规则**（参考片音效轻、偏亮、全压在人声底下；推响、配密、用合成音会显得吵、AI 味重）：
- 只在关键联动时刻配：元素互相作用、镜头大移动、关键揭示。数字滚动、打字、逐个弹出的小件不配；真人段的小标签、胶囊不配；切回真人不配。
- 模板自动配的也按这个来：真人段每个叠层最多一声（数据卡、前景大字 swoosh，身后大字 impact，贴纸、贴头字 pop，换章一下 click）；单卡版式只在第一项或完成时一声；进图形一声 whoosh。board 和卡通道具的自动配音是草稿行为，不按这个收。
- 图形段每秒 0.3–0.7 个；任意两个至少隔 0.5 秒（`meta.sfxMinGap`，挤在一起的只留优先级高的）；峰值落在动作落位那一刻。
- 每个音效峰值比人声中位低 1–6dB（`render_final.py` 逐个测）。
- 素材要偏亮、像空气和实物的声音，用 `references/sfx-palette.json` 指的库（`<你的音效库目录>` 下的 `音效库/mixkit_常用30`、`kenney_ui_audio`、`kenney_impact_sounds`）。不用低沉的合成嗖、正弦波叮、低音炮。打字音用的是 1386 键盘录音里最干净的一下。整套素材都能用 `scripts/fetch_sfx_library.py` 从公开渠道下载。换素材前先给用户试听，清单里写素材页上的原编号和原名。源清单 `references/sfx-palette.json` 所有工程共用；只改一条片子就复制一份进工程，用 `build_sfx.py --palette` 指过去。Mixkit 文件只留在本机，不随 skill 或素材分发。

| 画面事件 | 角色 | 现在用的素材 |
|---|---|---|
| 进图形、镜头大移动、东西飞来 | whoosh | 偏亮的转场嗖（1490、175） |
| 卡片滑出、代码窗飞出、大字落定 | swoosh | 纸张滑动、翻页（1530、1104） |
| 标签、贴纸弹出 | pop | 实录的"啵"（2364、2356） |
| 点按钮 / 关阀门、开关、换章 | click | 鼠标声（v 0）/ 开关声（v 1） |
| 勾选打勾 | check | 开关声 |
| 数字滚动的滴答 | tick | 打字机轻击 |
| 关键一下落定（皇冠、等号） | ding | 前台服务铃（931） |
| 挤爆、磕到底、大字砸下 | impact | 实录软闷响（Kenney impactSoft_heavy） |
| 东西落进水里 | splash | 真水声（1311） |
| 文档逐行出字 | type | 键盘声（1386 里截的一下） |

**BGM**：只用用户提供的、或本机有授权曲库里的音乐，没定时先出试听连播让用户挑（SKILL 第 1 步）。成片 BGM 比人声低约 12.5dB（`volume 0.135`；低 15dB 偏小，低 20dB 几乎听不见；要隐隐约约、千万不要盖过人声）。默认用你选定的有授权 BGM，曲子要求署名的，交付时提醒简介写署名。参考片的结构是前约 2 分钟只有氛围底、正文第一步开讲时鼓点进来（`bgm.dropAt`），用户没要求就整片同一音量。

## 11. 开头与结尾

开头（前 6 秒画面不停）：
- 符号法：0 秒给一个人人懂的符号（电池 = 假期余额），每一步踩一句台词。
- 片名法：先说一句冲突，片名放大落定，讲到时逐字扫光，再缩小退场（不变成角落胶囊）。栏目化的系列用固定片头 `custom/intro.tsx`（SKILL 第 3.5 步）。
- 素材法：冷开场第一帧就说话，4 秒切进高质感素材，左上清单逐条累积。

结尾：连续 2–3 次推拉跳切硬结束，或左上"点赞/收藏/关注"三连（`cta`）；没有片尾卡。

## 12. 不要做的事

- 退场动画盖住内容；实拍段只露一两秒就切走；两种进场切镜混用（拆景配圆球）。
- 字幕里的敏感词按基座 cangshu-koubo-wudongxiao 的 `references/captions.md` 替换：钱 → `$`（两条管线统一用 $，不用 ¥）、金额的万 → w、政策 → Z策、机构名不上字幕；人声消音先问。

- 不用参考片的品牌字和水印，水印用你自己的品牌（`meta.brand`）。
- 不编数据、评论、来源：画面上的字只用台词里有的、口播稿里有的或用户给的；屏幕出处写泛称，不出现境外平台或网站名（真实链接记进合规 / 自查记录）。
- 不在脸上放东西；不画名人、别人的品牌形象和受版权保护的角色（台词说"高达"就画原创机器人）。
- 不为了"满"硬塞元素：一个元素对一句话。
- 不连续两段用同一种单卡版式。
- 不穿模、不越界（清单见 `scene-guide.md` 第 5 节）。
