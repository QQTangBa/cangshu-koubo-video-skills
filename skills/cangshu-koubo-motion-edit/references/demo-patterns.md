# 参考片演示套路库（道具·隐喻·互动·抓注意力）

> 给 agent 读。用途：挑演示套路时查——参考片（一条同类知识口播爆款，真人段 ↔ 图形段交替剪法）里所有"用道具把意思演出来"的图形动画，拆成可复用的套路。写图形段前读第 2 节（20 个套路）和第 4 节（抓注意力），需要具体例子再查第 1 节。
> 本文件记录的是对标原片的样子（深色画布、1920×1080、粗描边道具），只借它的演示思路；画风按 style-bible 第 7 节（白卡 lux.tsx 或 toon 主题，SKILL 第 3.5 步定），写法按 scene-guide.md。文中的镜头和音效参数（推近 1.1–1.4 倍、摇过半屏去下一块区域、"配最响一档音效""配 boom"）也是对标原片的，不照搬：镜头按 style-bible 第 6 节，音效按第 10 节。
> 时间单位为秒，台词引用每处不超过 15 字。

## 1. 演示逐条记录

字段说明：
- **意思**：抽象概念；**隐喻**：用什么具体东西代表它。
- **道具**：外观（形状/配色/线条/占画面比例/描边阴影/平面或 2.5D）。

### D01 私信爆满的手机（5.5–12.5）
- 台词："后台经常收到私信"、"你到底有没有写逐字稿"
- 意思：很多人在问我同一个问题（社会证明 + 引出问题）。
- 隐喻：手机消息角标数字暴涨，消息被"拔"出手机放大。
- 道具：
  - 手机：白色粗边框（约 14px），右侧和底部露出浅灰挤出厚度（约 10px，2.5D），黑屏 App 界面（抖音 logo + "消息"列表，彩色圆头像），高约 70% 画高，居中，软阴影。
  - 红色计数角标：圆角胶囊 #ef4a5a，白色粗黑数字，底部有深红厚度，跨在手机右上角。
  - 私信气泡卡：深灰圆角卡 #2c2c30，左上头像和"网友"，右上抖音小图标，正文白色粗体；**背后叠一张偏移的暗卡**（叠层感）；宽约 45% 画宽。
- 步骤：①溶解进场时手机已在中央；②5.73 起角标 2→12→27→48→76→99+，每档约 0.2s 硬跳，列表同时插入新头像行；③7.2 手机左移约 40% 画宽，7.47 第一条气泡从手机里被拔出飞到右侧（滞后台词约 0.4s）；④8.9 白色圆形触点按在消息上，9.33 第二条气泡飞出；⑤10.27 第三次点按，10.47 手机变灰消失，旧气泡带模糊滑出，第三条气泡"你到底有没有写逐字稿?"放大到中央（镜头推进）；⑥11.8 气泡里"逐字稿"三个字在"稿"字尾变蓝。
- 常驻：无（靠计数和气泡连续进场撑节奏）。
- 文字：气泡原句；右下出处 `DM TEXT · ILLUSTRATIVE`。
- 核对帧：6.6、7.7、10.9。

- 台词："不是让AI帮我写"、"而是让AI帮我加持"
- 意思：表明立场：拒绝 AI 代写，接受 AI 加持。
- 道具：左上毛玻璃胶囊（图标 + 中文 + 彩色宽字距英文），右侧红色圆形 ✕ / 青色圆形 ✓（缩放弹出，疑似小过冲）。
- 步骤：新胶囊在下面淡入时旧胶囊变灰；✕/✓ 比胶囊晚约 0.2–0.3s（**先摆出来，再表态**）。
- 核对帧：参照 323.9（同样式的 ✕/✓）。

#### DA2 身后巨字 20 多万 → 缩成角标（23.2–25.5）
- 台词："从2万粉丝涨到了"
- 意思：用一个数字建立信任。
- 道具：人像抠图，身后黄色超粗数字（约 1/3 画高，被人头挡住一部分）；右上白色毛玻璃主页卡。
- 步骤：比"2 万"早 0.25s 淡入；"20 多万粉丝"说完的同一刻缩小飞到左上变成角标。
- 核对帧：24.0、25.6。

#### DA3 点阵日历（172.3–178.3）
- 台词："维持我更新频率"
- 意思：持续更新的天数。
- 道具：左上胶囊下方约 10×10 圆点矩阵，亮蓝 = 有作品，灰 = 没有；下方灰字"87 天 · 94 条作品"。
- 步骤：从左上逐行逐个点亮（约 15 帧扫完），像在数天数。
- 核对帧：173.0。

#### DA4 重写 ✗ → 修饰 ✓ + 96% 进度环（321.3–325.3）
- 台词："不是让你去重写"、"原本这个基础上"
- 意思：AI 只改了 4%，96% 是我的原话。
- 道具：毛玻璃胶囊"重写 REWRITE"（之后变暗）、"在原稿上修饰 POLISH IN PLACE"；红色 ✕、蓝色 ✓ 圆钮（有厚度、浮在胶囊右上方）；青色进度环（深色圆心 + 青色大字 96% + 白字"是我的原话"），外圈一颗高光点慢转。
- 步骤：先出胶囊 → 说完词后才打 ✕；第二胶囊出现时第一个变暗；✓ 晚一拍；进度环 34→96%（约 19 帧强 ease-out）。
- 核对帧：323.9。

#### DA5 身后大字（83.1 "3 个问题"、141.9 "1 第一步"、429.4 "多动脑 + 多练"）
- 意思：章节号或最终结论，最大号上屏。
- 道具：白色超粗大字（50–55% 画高），人像压在字前，人的头和手会挡住字。
- 步骤：提前 0.25–0.4s 淡入；"1"那次同时做 2 帧数码推近给重拍；结论句说完立刻撤。
- 核对帧：430.7。

## 2. 演示套路库（20 个）

每个套路写：适合的论点类型 / 需要的道具 / 标准演出步骤和参数 / 换主题示例（AI、职场、创业各一）。

### P01 注满：A 流入 B，B 的液面上涨
- 适合：积累、内化、"真正变成你的"、能力/信心/资本被充满。
- 道具：容器（大脑/电池/水杯/储钱罐）+ 输入源（管道光点/点阵弧线/飞入的小物件）+ 状态胶囊。
- 步骤：①容器先以低液面或灰色液出现（"没满"的状态要先被看见，静止 0.5–2s）；②输入开始：光点沿管道或弧线流入（点径约 12px，间距约 28px，速度约 0.5 画宽/秒）；③液面上涨 15–60 帧，近线性，液面一条浅色亮线 + 轻微波纹；需要时液色由灰变品牌色；④满了以后容器上方弹出结论胶囊（3 帧过冲）。涨满时刻对准句子最后一个关键词。
- 例：D15 后段、D27 末段、D45。
- 换题：
  - AI：用 AI 但自己思考 → 容器换成大脑，输入是"自己写的笔记"文件粒子，对照组是"直接复制 AI 答案"时液面不动。
  - 职场：复盘让经验沉淀 → 容器换成"经验值"电池，每一次复盘卡飞进去充一截。
  - 创业：现金流 → 容器换成储钱罐，输入是订单金币，旁边另一条管道是支出（见 P02）。

### P02 流走：东西穿过却留不住
- 适合：白忙、浪费、"看了等于没看"、留存问题、漏斗流失。
- 道具：管道 + 光点 + 中间的容器 + 出口阀门 + 红色状态胶囊"流走"。
- 步骤：①管道从源头绕进容器顶部；②光点**竖直穿过容器中线**，从底部出口流出画外，容器液面始终不涨；③红胶囊标在出口处；④转折句时把阀门换成"关"（2 帧，带小幅弹出），胶囊换成青色，液面开始涨（接 P01）。
- 例：D15。
- 换题：
  - AI：只收藏 AI 教程不实践 → 源头是"收藏夹"，光点穿过大脑流走；阀门换成"动手做"后液面涨。
  - 职场：开会不记行动项 → 源头是会议，信息穿过团队流走；阀门 = 会议纪要 + 负责人。
  - 创业：获客不做留存 → 源头是投放，用户光点穿过产品从底部流走；阀门 = 激活流程。

### P03 吸收：物件缩小飞进容器，被"吃掉"
- 适合：AI 读取资料、学习吸收、合并整合、"喂给它"。
- 道具：被吸的物件（文件夹卡/风格小卡/树/关键词）+ 吸收方（终端/大脑/机器）+ 吸收后的结果行（"✓ 已读取 24 份"）。
- 步骤：①物件缩到 0.2–0.3 倍，沿直线或弧线飞向吸收方（6–13 帧，先慢后快或缓入缓出）；②碰到边缘时消失（被边框裁掉或淡出）；③吸收方同时出现一行结果或状态变化（液面涨/打勾/计数）。多个物件错峰约 0.25s 依次吸入。
- 例：D08 末段、D09、D27、D35（文件拖进终端变附件）、D45（只留关键词飞进大脑）。
- 换题：
  - AI：给模型喂上下文 → 三张"需求文档/代码库/历史对话"卡被吸进对话框，输出"✓ 已理解 3 份"。
  - 职场：新人入职吸收公司知识 → 制度卡、项目卡飞进新人头像，头像下的进度环涨。
  - 创业：并购整合 → 小公司 logo 卡飞进大公司卡，大公司营收数字跳涨。

### P04 投进去以后被"使用"：物件进容器，在容器里以新形态出现
- 适合：一样东西在下一个环节被消费，因果链上的"交接"。
- 道具：被投的物件 + 使用它的机器（摄像机提词屏/播放器/作品卡封面位）。
- 步骤：①物件飞向机器并压缩（沿 Y 轴压成一条线或缩小，6–10 帧）；②机器内部同一时刻淡入物件的新形态（提词滚字/播放进度/封面），8 帧；③新形态立刻开始自己的循环动画（滚字、计时）。
- 例：D02（稿子掉进播放器就开始播）、D12（空稿飞进摄像机变提词）、D38（文档塞到提词器后面消失，屏幕出现正文）、D41（视频窗飞进作品卡封面）。
- 换题：
  - AI：Prompt 被模型执行 → 提示词卡飞进模型窗口，窗口里开始逐行生成结果。
  - 职场：需求文档交给开发 → 文档飞进 IDE 窗口，变成代码行在滚动。
  - 创业：PPT 进路演 → 商业计划书卡飞进投影幕布，幕布上逐页翻。

### P05 加工机 / 传送带：原料进 → 处理框 → 新版本出
- 适合：工具、方法论、"经过某一步就变样"、对比"别人的做法"。
- 道具：竖向机器卡（顶部 logo + 名称 + 一个可信数字，下半部黑色处理框 + ">>>"箭头）、横向传送带、输入件（带红色问题标记）、输出件（带"××版"标签）。
- 步骤：①输入件在左侧、问题标签先弹出；②机器在中间淡入放大；③输入件向右滑进处理框被裁掉，同时问题标签缩成小点飞走；④约 0.5s 后从右边缘吐出新版本（先是一条线再展开，4 帧）；⑤如果这条路是"别人的做法"，整条线降饱和到约 40% 透明度。
- 例：D24；终端版本见 D09、D35。
- 换题：
  - AI：同一份需求经过 Cursor 和经过人工 → 两台机器并排，输出质量不同。
  - 职场：周报模板机 → 杂乱聊天记录进，结构化周报出。
  - 创业：自动化 SOP → 客户咨询进，报价单出，旁边计数"每天省 3 小时"。

### P06 从母体长出：子元素从父元素边缘/节点里冒出来
- 适合：展开解释、补充证据、"这个东西包含什么"、因果拆分。
- 道具：父元素（节点/文档/胶囊/表盘/手机）+ 子元素（卡/胶囊/清单）。
- 步骤：①父元素先给一个信号（节点点亮 1 帧 / 边缘冒出一个小深色块）；②子元素从锚点以 20% 尺寸放大，同时向外移 5–15% 画宽（3–8 帧，ease-out，可轻过冲）；③收回时沿原路反向（ease-in，约 4 帧）。
- 例：D16（术语卡从节点长出又收回）、D29（功能卡从手机背后滑出）、D36（✓胶囊从文档边长出、数据卡从胶囊长出）、D40（脉络卡从表盘长出）。
- 换题：
  - AI：一个模型名点开 → 长出"参数/价格/上下文长度"三张小卡。
  - 职场：一个岗位节点 → 长出"职责/薪资/晋升路径"。
  - 创业：一个产品 → 长出"用户/渠道/收入"三张卡，说完收回。

### P07 视线 / 注意力用虚线表示
- 适合：注意力被什么占据、依赖、看哪里、"被绑住"。
- 道具：眼睛胶囊"你的视线"、虚线（末端圆点）、目标（提词器高亮行/屏幕/某张卡）、链条图标、视线时间轨（红色满条 vs 青色短竖条）。
- 步骤：①胶囊淡入；②虚线从胶囊描到目标（6–7 帧，线性），目标对应位置出现高亮带或瞄准环；③被依赖：虚线中点弹出红色链条图标（4 帧过冲），虚线由白变红；④对比轨：红条一路长满 vs 青轨上只落几根短竖条，每落一根，目标高亮闪一下（约 0.3s）。
- 例：D12、D38。
- 换题：
  - AI：写代码一直盯着 AI 补全 → 视线虚线连到补全浮窗，变红加链条；对比"先想再看"只有几次瞄。
  - 职场：开会刷手机 → 视线虚线从人连到手机而不是 PPT。
  - 创业：创始人盯数据面板 → 一条全程盯 DAU 的红条 vs 只在周会看一次。

### P08 两轨对比：同起点、同速度，差距"跑"出来
- 适合：快慢、多少、前后、我 vs 别人。
- 道具：横条（青 vs 灰/红）、点阵（满 vs 1 个异常）、段条（连续 vs 断续越来越短）、3D 立方柱、粗轨 vs 细碎轨。
- 步骤：①两行标签先出；②两条**同时起跑、同样速度**（约每帧固定增量），短的先停、长的多跑——差距在时间里被看见；或者先灰后蓝接力；③终点弹出倍数胶囊或大字（3 帧过冲）；④尾数在之后 1s 里还慢慢涨 1–2。
- 例：D03、D11、D31、D36、D43、D32 立方柱。
- 换题：
  - AI：人工翻译 vs AI 翻译耗时。
  - 职场：拖延 vs 立刻做的完成曲线。
  - 创业：自建 vs 外包的上线天数。

### P09 时间轴：时间 = 横向空间，镜头沿着走
- 适合：回顾过去、阶段划分、"在此之前/之后"、转折点。
- 道具：横向细轴 + 月份刻度（略带透视）、青色游标点、日期胶囊、挂在节点下的事件卡、虚线括号（时间段）、描色段（某段之后）。
- 步骤：①先拉远露出更早的刻度；②游标沿轴往左（过去）或往右（未来）走，镜头一起横移（约 0.7–1.2s）；③停下弹出日期胶囊，往下描出竖线，竖线下端弹出事件卡；④用描色（如青色）表示"从这里开始有了某样东西"，用虚线括号表示"某样东西之前"。
- 例：D06、D07、D08。
- 换题：
  - AI：大模型产品发布前后 → 轴上一段描青，括号"有 AI 之前"里是手工流程卡。
  - 职场：入职 3 个月、6 个月、1 年的变化。
  - 创业：从 0 到第一个付费客户的关键节点。

### P10 流程线行进：卡片沿节点轨道滑，到站换状态
- 适合：步骤、工作流、"做到哪一步了"、总结整套方法。
- 道具：横向节点线（圆形图标节点 + 下方文字）、在线上行走的卡、状态胶囊、虚线占位卡（下一站）。
- 步骤：①流程线淡入（节点从左到右约 0.15s 一个）；②卡滑到下一站（10–13 帧 ease-in-out），连线被品牌色从左往右填充，到站时节点点亮、卡上胶囊换字；③全部走完可以翻转成最终产物（视频块）；④总结时用"上摇露出 → 逐个点亮（约 0.23s/个）→ 砸章"收尾。
- 例：D20、D25、D39。
- 换题：
  - AI：Agent 工作流"规划 → 调用工具 → 检查 → 交付"。
  - 职场：需求"提出 → 评审 → 开发 → 上线"。
  - 创业：MVP"想法 → 原型 → 用户访谈 → 付费"。

### P11 速度/产量用计数器说话
- 适合：效率对比、规模、"快到离谱"或"慢到离谱"。
- 道具：计数卡（大数字 + 单位 + "示意"）、进度条、REC 计时、星芒光标、打字计数。
- 步骤：①慢：逐键打字，计数 0→11，进度条几乎不动，持续一整句（2–3s）；②快：占位行一秒好几行往下长 + 计数 0→12,480 强 ease-out（约 1.4s）；③快进：计时 140 倍速跑完，再冻结成一张卡；④计数时长按整句配，数到终值的那一刻对准句尾关键词。
- 例：D07、D13、D41、D04。
- 换题：
  - AI：AI 一分钟写完 50 个测试用例 vs 手写 2 个。
  - 职场：自动化报表 1 秒生成 vs 手工 2 小时（计时快进）。
  - 创业：上线首周注册数狂飙。

### P12 模拟真实操作
- 适合：讲工具怎么用、让观众"看见过程"。
- 道具：键盘、终端打字机、输入框 + 发送键、手机 App、点击触点/涟漪、白闪换页、快门。
- 步骤：①白色圆形触点按下（缩小）或涟漪（约 8–10 帧）；②过曝白闪 3–4 帧切换页面；③打字机约 2 帧一字、跟在口播后面约 0.3s（像在记录讲者说的话）；④发送后输入内容变成气泡飞走。
- 例：D01、D07、D23、D28、D29、D42。
- 换题：
  - AI：在 Claude 里上传文件、点运行、看结果。
  - 职场：在飞书里一键建群、发审批。
  - 创业：在后台点"上架"，订单通知弹出。

### P13 盖章 / 判决
- 适合：结论、定性、立场、"这就是答案"。
- 道具：黄色贴纸章（黑描边，-5° 到 -8°）、红色指纹章、✕/✓ 圆钮、红色批注框。
- 步骤：①章以 1.6–2.2 倍出现，2–3 帧砸到 1.0，基本不回弹，配最响一档音效；②常比关键词早 0.2–0.8s（先亮结论）；③✕/✓ 比所属胶囊晚 5–10 帧（先摆出来，再表态）。
- 例：D05、D10、D37、D39、DA1、DA4。
- 换题：
  - AI：给 AI 生成的代码盖"需要人工复核"。
  - 职场：给一份方案盖"老板会问的问题"。
  - 创业：给一个想法盖"伪需求"✕。

### P14 炸开再重组
- 适合：拆解、消化、"把别人的资料变成自己的逻辑"、结构化。
- 道具：一张集合卡（内含 N 行）、散开后的小卡（白色、有厚度、轻微 3D 倾斜）、链节点、黄色箭头和树枝线、根节点、彩色标签胶囊。
- 步骤：①集合卡外壳模糊淡出（约 5 帧），各行变独立卡；②向四周炸开（约 10 帧 ease-out），之后慢漂 0.4s；③说到"形成逻辑"时，挑出有用的卡排成横向链，箭头逐段画出；④说到"整体脉络"时横链折成竖列，加根节点，树枝线先主干后分支；⑤标签按口播节拍逐个弹出。
- 例：D27。
- 换题：
  - AI：把一篇论文炸开 → 挑出 3 个结论连成"为什么 → 怎么做 → 局限"。
  - 职场：把一堆客户反馈炸开 → 归成 3 类问题的树。
  - 创业：把竞品分析炸开 → 重组成自己的定位链。

### P15 网络 / 边界扩张，再坍缩成一个成果
- 适合：领域很大、知识边界、影响力范围、累积成资产。

## 4. 抓注意力的精髓

### 4.1 "每一秒都在动"是三层叠出来的
1. **底层（从不停）**：B 世界水印字墙跟镜头一起动并且自己慢漂；A 世界房间 RGB 灯色相 3–6s 一圈，人脸跟着变色。所以即使图形不动，画面也不是死的。
2. **中层（道具自带循环）**：提词屏滚字（97.2–98.9、111–120、343–354）、管道光点（111–120）、REC 计时（41.8–48.9、396–398）、播放器时间码（37.2–41.6）、波形播放头（44.0–46.1）、喇叭声波（110.3）、轨道点慢转（135–139）、"…"三点打字（396.4 起）、卡间光点往返（278.9、282–283）、尾数慢收（264–265）。规律：**任何一个道具停下来超过 1s，就给它一个自己的小循环。**
3. **上层（事件）**：每 0.3–1.0s 一个新动作（出现、飞入、变色、计数），B 段 13s 里有 8–15 个独立动效。
- 真正全静止的时候都是故意的，而且后面一定接大动作：125.0–127.2 只有一个节点 → 星座网铺满；151.2–153.6 空选题卡 → 灵光乍现；392.33–395.6 手机静止 3.3s 本身就是"发懵"→ 快门按下；A 世界 79.8–83.1 留白 3.3s → 身后巨字"3"+ boom。

### 4.2 演示和台词怎么咬合
- **动词 = 动作，误差小于 0.1s**：灵光乍现 154.07 灯泡闪；去掉 202.4 "AI 味"飞走；剪掉 415.5 剪刀张合；拉回来 416.47 补位；瞄一眼 348.6 竖条 + 提词高亮；离不开 99.27 链条弹出；打开 395.6 快门按下；发懵 396.4 气泡弹出；内化 241.47 树被吸进大脑。
- **名词提前 0.3–1.0s 出现**：让观众先看到再听到（"深入"早 0.8s、"维持"早 1s、"不熟悉"胶囊早 0.9s）。
- **结论提前，判断滞后**：重中之重章比台词早 0.8s（49.7）；但 ✕/✓ 永远比胶囊晚一拍（18.6、321.73、322.93）——先把选项摆出来，等观众心里有了判断，再盖章确认。
- **数数节拍**：260 秒附近"一二三四五"5 行间隔 8–10 帧匀速落下；239 秒附近"什么样"×3 标签约 8 帧一个；381 秒附近"第一点/第二点/第三点"三行几乎零误差对上。口播一列举，画面就按同样的节拍落子。
- **计数时长 = 整句时长**：−118 字覆盖"重复啰嗦…全部去掉"整句（312.0–313.6）；粉丝 0→100 万从"从"跑到"级别"（46.37–48.1）；大脑灌满和 58 期同时落在"脑子"（424.0）。
- **转折词动镜头**："但是""然后""那么""所以""最重要的是"出现时，镜头推/摇/甩或者换世界（41.63、279.73、331.57、337.77、417.47）。

### 4.3 一根线牵着观众：主角道具贯穿全片
- 逐字稿纸卡出现十多次，每次状态不同：掉进播放器（36.3）→ 被盖"重中之重"（49.7）→ 手敲（65.4）→ 从终端里生出来（75.9）→ 变 AI 味（87.5）→ 被清空（94.4）→ 飞进摄像机（96.3）→ AI 写成长报告（105.7）→ 从手机里抽出来（272.9）→ 被红线批改（290.4）→ 翻面成错题本（298.2）→ 原地清理（311–318）→ 清理版（319.05）→ 盖"原创"章（339.1）→ 塞进提词器（342.4）。观众会一直追"那张纸后来怎么了"。
- 回收前文：报告卡出画后在 206.4 翻回来；摄像机在 93、342、383 三次出现，每次屏幕内容不同；大脑在 113（流走）、241（灌满）、417（灰→蓝灌满）三次出现，正好是"问题 → 方法 → 结论"；"20 多万"在 23 秒开头和 425 秒结尾首尾呼应。
- 第二次出现就快放（265.5 清单间隔从 8–10 帧压到约 2 帧），观众已经看懂的东西不浪费时间。

### 4.4 用"空"制造悬念（蔡加尼克效应）
- 先画空位再填：空选题卡（151.2，2.4s）、03 节点上方虚线空卡（207.6）、错词卡灰色空槽（300.9）、清理版两侧虚线框（326.0）、阶梯虚线框（400.3）、"0 稿件"虚线框（384.93）。空位一出现，观众就在等它被填满。
- 疏密交替：疏的画面总是放在"马上要变密"之前（空节点 → 星座网，空卡 → 灵光乍现）。

### 4.5 颜色语义从不乱用，状态翻转只换颜色
- 青 = 我的 / 好；红 = AI 味 / 错 / 被绑；黄 = 重点 / 成果；灰 = 旧的 / 别人的。
- 所以观众不用读字就知道态度：87.53 高亮从青变红 = "变坏了"；420–424 大脑液体从灰变蓝 = "开始用脑了"；205.87 整条线变灰 = "这不是我"；99.27 视线虚线从白变红 = "被绑住了"。

### 4.6 什么时候用演示，什么时候用数据卡
- **演示讲机制**（是什么、怎么发生、因果关系），占画面主位（中/左，45–70% 画高），由主线道具承担。
- **数据卡讲证据**（有多大、谁说的），永远是演示的旁注：在关键句时从右侧滑入或从主体边缘长出，说完就淡出或变暗下沉，主体留下。典型三拍：演示建立画面 → 数据卡补证据 → 数据卡退场、回到演示。例：111–120 大脑演示 + MIT 卡；87–93 AI 味文档 + 爱用词卡 + 听辨卡；262 口述横条卡夹在"口述清单"和"白板教案"两段演示之间；333 秒"省时间"胶囊长出 42 vs 11 横条卡。
- **数据卡自己也要动**：条要长、点要填、数要滚，一个数字至少带一个运动源（圆点条、指针、滑块、柱高）。
- **A 世界承担态度和结论**（左上角标、✕/✓、身后大字、进度环），B 世界承担演示。A 段 3–7s 一段，是"喘口气 + 一个态度"；B 段最长 28s 一刀不切（181–209），全靠镜头在画布上走。

### 4.7 可信感
- 真实截图嵌在白卡或手机里（60 作品卡、273 妙记真实转写、388 创作者中心截图），数字后面挂口径胶囊（推算/实测/厂商称/示意）和右下微缩出处。动画再夸张，观众也觉得"是真的"。
