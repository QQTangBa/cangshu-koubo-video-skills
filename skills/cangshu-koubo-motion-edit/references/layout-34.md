# 3:4 画面规范（1080×1440）和拍摄建议

对标是 16:9 横屏。3:4 窄了 44%、高了 33%，横向铺开的东西都要改成竖向。

## 1. 拍摄建议（用户问怎么拍、或拍之前给用户看）

| 方案 | 3:4 可用画幅 | 建议 |
|---|---|---|
| 竖拍 4K（2160×3840） | 2160×2880 | 首选：粗剪统一缩到 1080×1440，4K 缩下来画质更干净 |
| 竖拍 1080p（1080×1920） | 1080×1440 | 手机自拍常见，够用 |
| 横拍 4K（3840×2160） | 1620×2160 | 可以，左右素材全裁掉 |

不管哪种，粗剪后都是 1080×1440，模板在这上面放大：真人段总推近倍数（zoom × 慢推 × punch）别超过约 1.2。

- 机位固定，人居中，身体别左右大幅晃：抠像、身后大字、左上卡片都按人居中排。
- **头顶留白 ≥15%，能到 20% 更好**：顶部进度条和身后大字都用这块。样片头顶留得少，"溢价"大字只能缩到 72%，才能既不碰进度条、又不被头挡太多。
- 脸中心大约在画面 38% 高度（`from_base.py --place 0.38` 会自动对齐）；手势别长时间挡在下方字幕带。
- 背景简单、和头发衣服有反差，光线稳定、别背光：macOS Vision 抠像才干净。
- 衣服纯色：数据卡可以压在胸口（`dataCard pos: chest`）。
- 讲法：
  - 论点之间停半拍。换镜头、进图形都卡在句子交界，粗剪会把超过约 0.35 秒的停顿剪掉。
  - 讲机制、举例、给数据的段落会被图形盖住（约一半到六成时长），可以连着讲。
  - 表态、结论、转折句看着镜头说，那几句会回到真人画面。
- 说错了整句重说一遍，不用停机，剪的时候留最后一遍。
- 氛围：深色房间 + 侧光最接近对标；有 RGB 氛围灯就开循环模式，没有就用 `meta.ambient` 模拟（默认透明度 0.32，素材偏暖偏亮时调到 0.15–0.25）。

## 2. 安全区

```
y 30–74     顶部进度条（全片常驻，任何元素都不进）
y 84–300    叠层带：左上章节导航卡 / 数据卡（角落小字胶囊 tag / pill 默认不用）
y 110–1090  图形段元素的安全区（kit.tsx 的 SAFE_Y）；左右 x 40–1040
y 300–1100  主体：人（A）或主角道具（B）
y 1100–1250 字幕带（字幕框顶边 y≈1150、中心约 1190，单行 ≤14 字）
y 1250–1440 平台遮挡带：小红书、抖音全屏时标题和按钮会盖住，别放信息
```

## 3. 横屏手法改竖版

| 16:9 原版 | 3:4 改法 |
|---|---|
| 左上竖列章节导航 | 顶部分段进度条 + 每章开头左上导航卡（最多 5 项） |
| 右上数据卡 | 左上毛玻璃 `metric`，或通栏 `dataCard`（`pos: top` / `chest`） |
| 关键词贴头两侧 | ≤3 字放脸两侧；>3 字叠到头顶上方两行 |
| 身后大字 | 头顶附近、只挡一角，位置交给 `fit_bigtext.py` |
| 横向流程、时间轴 | 改竖向，从上到下 |
| 竖柱状图 | 改横条（标签在条上方） |
| 左右两卡对比 | 上下两卡，或两张卡并排但缩小（单张 ≤470 宽） |
| 星座、环形图 | 方形构图天然适配，直接居中 |
| 手机 mockup | 竖屏物体放竖屏画面，可以放大到画面高度 60% |
| 双语字幕 | 默认只留中文 |

## 4. 信息密度

- 图形段同屏 ≤3 个主体，单卡正文 ≤4 行。
- 正文字号 ≥36px，卡片标题 ≥46px，中文标签 ≥22px（英文小字、出处层例外，见 style-bible 第 7 节）。
- 一个画面一个视觉焦点：新东西出现时，旧的压暗、缩小或并进别的元素。
