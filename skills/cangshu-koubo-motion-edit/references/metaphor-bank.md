# 隐喻创意库：把一句话"演"出来

写图形段之前，每个论点都过一遍第 1 节的流程，再到第 2 节找现成的隐喻，最后用第 3 节的手法让它"活"起来。第 2 节里写的道具参数名（brain.fill、pool.level…）对应草稿道具 `src/scenes/props.tsx`，只当思路参考；成片在手写场景里按定好的画风重画（白卡 lux.tsx 或 toon.tsx + 主题，`scene-guide.md` 第 4 节；toon 的 `lbkit.tsx` 已有罐子、水桶、哑铃、旋钮、小狗、彩票、噪点图等现成道具）。图标可以用 Tabler 的 5184 个（`TablerIcon`，名字查 `src/icons.json`，例如 pig-money、hourglass、magnet、rocket、ladder、umbrella、anchor、bomb、key、lock、target、trophy、flame、plant-2、balloon）。

2. 隐喻对照表（按关系类型）

## 1. 发散流程（每个论点都跑一遍）

用下面这段当作给自己的提示词，逐条写出答案再选：

```
论点原句：____（≤20 字）
① 核心关系：这句话里谁对谁发生了什么？从「增加 / 减少 / 流入 / 流走 / 阻断 / 替代 / 选择 / 对比快慢 / 对比多少 / 累积 / 转化 / 依赖 / 扩张 / 坍缩 / 筛选 / 竞争 / 循环 / 失衡 / 突破 / 隐藏」里选 1–2 个。
② 物理类比：这个关系在物理世界里长什么样？至少想 3 个，分别来自不同母题：
   液体（灌、漏、溢、蒸发）· 重力（掉、压、翘、塌）· 生长（发芽、长高、枯萎）· 机械（齿轮、传送带、开关、阀门）·
   容器（杯、桶、池、罐、电池）· 空间（门、墙、梯子、迷宫、坑）· 交通（赛道、堵车、捷径、加速）· 能量（电量、火、光、磁）·
   人群（排队、挤、散、围观）· 工具（剪刀、放大镜、锤子、筛子、漏斗）
③ 前后两个状态 + 触发动作：画面开头是什么样？结尾是什么样？中间那个动作由台词里哪个动词触发？（动词出口那一下，误差 ≤0.1s）
④ 夸张一档：数量 ×10、尺寸差 ×3、速度差 ×5、颜色翻转（青↔红、灰↔蓝）。
⑤ 连续性：前面出现过的道具能不能接着用？（水池变浅、机器人飞回来、同一张稿子换状态）
⑥ 打分（每项 0–2）：一眼看懂 / 会动（不是静物）/ 有反转或冲突 / 画得出来（所选画风一两个组件能画完）/ 能接上下文（复用前面出现过的道具）。总分最高的那个用。
⑦ 落地：写成道具 + 参数 + 时间点，数据卡作为旁注从道具边上长出来。
```

**一个完整例子**："现在 95% 的需求都是增删改查，需求本身就这么浅"
- 核心关系：多少（95%）+ 浅（深度低）
- 物理类比：A 百格图填满 95 格；B 水池水位见底；C 尺子量出来只有 1 厘米深；D 泳池里的人站起来水才到脚踝
- 前后状态：先是一张正常的需求单（增删改查、加按钮、改开关）→ 需求单倒下变成浅浅的托盘，"浅"字出口时落定
- 夸张 / 荒诞：一个人一头扎下去，头直接磕到底，"需求就这么浅"从磕底的地方弹出来
- 连续性：真人段的 95% 数据卡直接变形成这张需求单；倒水用的是第一段水箱的那根水管 ✓
- 落地（样片 v14 的做法，见 `custom/stock2.tsx`）：数据卡变形 → 工具栏依次点亮 → 鼠标点"增" → 倒成浅盘、水管倒水 → 扎猛子磕底 → 弹出"需求就这么浅"

### 1.5 四档大胆度（每个论点四档都要写，再选）

| 档 | 是什么 | 什么时候选 |
|---|---|---|
| 直白 | 把台词里的词摆成卡片 | 只作兜底，不单独成拍 |
| 比喻 | 换成大家都认识的实物，演出这个关系 | 需要可信、讲数据的地方 |
| 夸张 | 数量、尺寸、速度、反差放大一档 | 要观众记住的论点 |
| 荒诞 | 让道具做一件出人意料、有点好笑的事 | 情绪点、吐槽点、结论前一拍 |

规则：一条视频里至少一半的 B 段论点选到"夸张"或"荒诞"，前提是 1 秒看懂。四档写进工程的 `创意发散.md`（表格：台词｜核心关系｜四档候选｜打分｜选择和理由），示例见第 1 节的完整例子。
样例："需求就这么浅" → 直白：盖章；比喻：水池水位见底；夸张：尺子量出 1 厘米；荒诞：有人一头扎下去，头戳池底腿朝天（选荒诞，叠在比喻上）。

### 1.6 灵感母题库（发散时逐个扫一遍，看哪个能套）

动效师讲抽象概念几乎都用"人人认识的实物"（火箭起飞、握手、命中靶心、植物生长、存钱、机器人开机）。按这个思路扩成下面这些母题，都自己画，不接现成的动画素材：

- **液体**：倒满的杯子、漏水的桶、溢出的锅、蒸发、水坝决堤、海啸浪头、冰山（水面上一小块）、水滴汇成河
- **重力**：多米诺连锁倒下、叠叠乐抽一块塌、积木塔、跷跷板、天平、砸下来的铁砧、气球升空 / 气球被扎破
- **生长**：种子发芽、树长出金币（摇钱树）、杂草蔓延、修剪枝叶、枯萎、年轮
- **机械**：齿轮咬合、传送带、流水线克隆、开关、阀门、发条、自动贩卖机、复印机吐出一模一样的东西、模具压出同款
- **空间**：梯子、楼梯/扶梯（两人同速到顶）、迷宫、捷径、悬崖、跨不过的沟、搭桥、门锁和钥匙、拼图最后一块、地图插旗、登山插旗、金字塔塔尖
- **人群**：排队、挤在框里、围观、拔河、赛跑同起点、接力、羊群跟风、站队两边、一个人逆行
- **能量**：电池掉电、火越烧越旺 / 熄灭、灯泡亮起、磁铁吸附、信号格、温度计、压力锅冒气、导火索燃烧
- **时间**：沙漏、计时环、日历翻页、时间轴倒带、钟表快进
- **容器**：储钱罐、保险箱、垃圾桶、漏斗、筛子、网兜、口袋（把人才揣进兜里）
- **对抗**：拔河、天平、跷跷板、PK 两条血条、棋盘、盾牌挡箭
- **信息**：放大镜、雷达扫描、扩音器、回音、过滤网、雪片般的通知、信号塔、迷雾里的灯塔
- **转化**：毛毛虫变蝴蝶、原石打磨成钻石、面团进烤箱变面包、碎片拼成一个整体、网络坍缩成金币、雪球越滚越大

## 2. 隐喻对照表（按关系类型）

格式：**关系** — 视觉 — 道具/参数 — 换题例子（AI / 职场 / 创业）

### 增减与积累
- **积累 / 内化** — 液体灌进容器，液面上涨，满了弹结论 — brain.fill / pool.level / battery.level，连线 pipe — AI：自己动手的笔记灌进大脑；职场：每次复盘给经验电池充一格；创业：订单金币进储钱罐（icon pig-money + coins）
- **白忙 / 留不住** — 光点穿过容器流走，液面不涨；装阀门后才开始涨 — brain.through + valve.closeAt — AI：收藏 100 个教程却不动手；职场：开会不记行动项；创业：投放来的用户从底部漏走
- **复利 / 滚雪球** — 雪球下坡越滚越大 — snowball — AI：每天用 AI 省 10 分钟，一年后；职场：每周一篇总结；创业：老用户带新用户
- **衰减 / 透支** — 电池掉格变红闪烁 — battery.level 降、低于 20% 红闪 — AI：一直靠 AI 不思考，脑子电量掉；职场：连轴转；创业：现金流见底
- **门槛降低** — 高墙变矮 / 梯子出现 — icon ladder 从下往上长，墙（text 卡）缩矮 — AI：会说话就会编程；职场：入行门槛；创业：建站成本

### 流动与转化
- **加工 / 方法论** — 原料进机器、处理框闪箭头、新版本吐出来 — machine.feedAt/outAt — AI：AI 稿进"去 AI 味"机器出改写版；职场：杂乱聊天记录进周报机；创业：客户咨询进 SOP 出报价
- **交付 / 使用** — 物件飞进机器后在机器里换形态 — exit into + 目标道具开始循环（camera 提词滚字 / player 播放 / code 打字）— AI：提示词飞进模型窗口开始逐行生成；职场：需求文档飞进 IDE 变代码；创业：计划书飞进投影开始翻页
- **喂资料** — 小文档沿线飞进去 — links style particles — AI：喂上下文给 Agent；职场：新人吸收公司资料；创业：竞品资料喂进分析
- **筛选 / 转化率** — 漏斗进很多、出很少，多余的溢出 — funnel.pass / overflowAt — AI：100 个 AI 点子只有 3 个能落地；职场：100 份简历留 3 个；创业：注册→激活→付费

### 替代与竞争
- **替代** — 一排齿轮里中间那个掉下去，换成青色 AI 齿轮继续转 — gears.replaceAt — AI：AI 换掉流程里一个环节；职场：岗位被替代；创业：外包被自动化替代
- **内卷** — 跑轮里拼命跑却原地不动；人群被框子挤成一团 — wheel.runAt / crowd.squeezeAt — AI：大家都用 AI，效率提高了但没人轻松；职场：加班竞赛；创业：价格战
- **存量 vs 增量** — 水池进水停住，池里的人越来越挤 — pool.inflowStop + crowd — 互联网红利结束、岗位不增、用户见顶
- **比快慢 / 比多少** — 两条同时起跑，短的先停、长的多跑一会儿；点阵两行 — bars / dots / data — AI：人工 2 小时 vs AI 11 分钟；职场：拖延 vs 立刻做；创业：自建 vs 外包上线天数
- **差距被抹平** — 天平先歪再晃回正中 — scale.tilt 0.7→0 — 北大 vs 中专有了 AI 结果差不多；大厂 vs 小厂工具一样；大公司 vs 小团队

### 选择、风险与因果
- **权衡 / 此消彼长** — 跷跷板一边砸下重物另一边翘起 — seesaw.dropAt / tilt — AI：省下的时间 vs 失去的手感；职场：薪资 vs 成长；创业：增长 vs 利润
- **依赖 / 被绑住** — 视线虚线连到目标，中点弹红色链条、虚线变红 — links style sight + mark cross — AI：写代码离不开补全；职场：离不开领导拍板；创业：依赖单一渠道
- **瓶颈** — 很多光点挤在瓶口只能一个个过 — funnel.pass 很小 + crowd — AI：算力不够；职场：审批卡在一个人；创业：交付能力跟不上订单
- **风险 / 爆雷** — 炸弹图标引线燃烧、到点炸成碎卡 — icon bomb(anim shake) → exit fade + 碎卡 fly — AI：AI 生成内容没审就发；职场：埋雷的需求；创业：合规风险
- **灵感 / 想通** — 灰色灯泡亮起、放射线扩出 — bulb.onAt — 想明白的那一句

### 扩张与结构
- **知识边界 / 影响力扩张** — 星座网铺开、节点点亮、外圈一圈圈扩 — network.growAt / lights / rings — AI：AI 技能树；职场：人脉；创业：城市渗透
- **积累变成资产** — 网络坍缩成一枚金币 — network.collapseAt + coin — 学的东西变成能接的单、人脉变成机会
- **拆解 / 重组** — 一张集合卡炸成小卡，挑出几张连成链，再折成树 — exit fade + 多张 fly from + layout chain → tree — 把论文变成自己的逻辑；客户反馈归类；竞品分析变定位
- **步骤 / 进度** — 流程节点逐个点亮、线条填色 — steps.activeAt — Agent 工作流；需求上线流程；MVP 四步
- **增长** — 折线描出、终点脉冲；3D 立柱逐根顶起 — chart / bars3d — 播放量、粉丝、营收

### 注意力与情绪
- **焦虑 / 压力** — 仪表盘指针打到红区微微抖 — gauge.to 0.9+ — 截止日、KPI、现金流
- **时间流逝** — 沙漏晃、计时环转满 — icon hourglass(shake) / ring — 15 分钟理脉络、拖延
- **吸引 / 获客** — 磁铁吸住一群小点 — icon magnet(pulse) + particles 连线 — 好内容吸粉、产品吸用户
- **起飞** — 火箭图标从下往上冲出画面，带运动模糊 — icon rocket + enter slide up + 镜头跟 — 爆款、融资后增长

## 3. 让动画生动的 10 个手法

1. **拟人**：道具有反应——机器人启动时眼睛亮、胳膊摆；小人跑步时冒汗；电池没电时红闪。观众会把情绪投到道具上。
2. **预备动作**：大动作前先反向收一下（物件飞走前先缩 0.95 再冲出去；盖章前先抬高）。
3. **挤压拉伸**：落地的东西先压扁再弹回（盖章 1.8→1；弹出用 `popIn`，自带过冲）。
4. **跟随动作**：主体停了，附属的还在动（天平停下托盘还晃一下、液面停下波纹还在）。
5. **物理感**：掉落用加速（easeIn），飞行用缓入缓出，弹出带过冲；液体有波纹，重物落下要有冲击音。
6. **反差**：大小（一个巨人 vs 一群小人）、颜色（灰→蓝、青→红）、速度（同时起跑一快一慢）。
7. **意外变形**：A 变成 B（网络坍缩成金币、稿子飞进摄像机变成提词、雪球变成"一年后"）。观众最爱"原来是这样"。
8. **空位悬念**：先画虚线空位（ghost），讲一项填一项。
9. **镜头当叙事**：转折词时镜头推拉；新内容从已有元素身上长出来，不是镜头移过去露出摆好的东西。
10. **一直有底噪**：任何道具静止超过 1 秒，都要有自己的小循环（滚字、光点、浮动、闪烁）。

## 4. 反面清单

- 只把台词里的词摆成卡片 = 换了样子的字幕。每个图形段都要有一个主角道具把机制演出来。
- 隐喻要一眼懂：观众 1 秒看不懂就换。不用需要解释的抽象符号。
- 一个画面只演一个关系；演完再接下一个，不要同屏三个隐喻抢注意力。
- 不画名人、不画别人的品牌形象和受版权保护的角色（台词说"高达"就画原创机器人，标"AI 机甲"）。
- 数据卡不抢主位：从道具边上长出来，讲完就退回去。
