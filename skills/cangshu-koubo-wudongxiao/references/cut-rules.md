## 1. 剪辑表格式

`$P/edl.json`：`{"source": "$P/source.mov（第 0 步的输出）", "keep": [{"from": 秒, "to": 秒, "h": "...", "pause": false, "say": "这段说什么、删了什么"}]}`，时间全是 `source.mov` 的时间线（下文说的「原片时间」都指它）。音频和视频起点不一致的素材 `cut_takes.py` 会直接报错：转写按解码时间、切片按容器时间，差多少就把剪点切错多少，句尾字被切掉、口型对不上都是这么来的（实测有素材差 0.19 秒）。
- 不写 `h` 的边界，`cut_takes.py` 会吸附到声音起止处（前留 0.06 秒、后留 0.08 秒）；`h: "from" | "to" | "both"` 那一边按帧硬切。
- 第 0 段（系列片头）写 `"pause": false`，片头里的停顿一律不动。
- **没有系列固定片头**的素材，在 edl.json 顶层写 `"intro": false`：各脚本就不把第 0 段当片头、不把第 1 段开头当响指，变速从头开始，第一个剪点也做融合。不写默认有片头。
- `edl.py rebuild` 以当前剪辑为底重写剪辑表，之后所有 keep 都是 `h: "both"`、`pause: false` 的精确边界；再改就再跑 `rebuild`（`--remove` 给剪辑后时间），不手改秒数。
- 剪辑后时间要换回原片时间时用 `edl.py map`，别手算（中间有变速、有删段，手算一定错）。

## 2. 口误和重复

- 同一句说了几遍留最后一遍；一整段重录了，前面那遍整段删。拿不准的列出来问。
- 说一半停下的半句、半截词、句中重起（「能把，能把」「所以我们 所以我们」「能把公…这个…能把」）删前面那遍，从第二遍的头接上。删的时候连带删掉被吞进去的附带字（比如「团队吧，能把」删第一个「能把」时「吧」也没了，字幕跟着删「吧」）。
- 讲者的顺序不动，正常内容不删，插话、吐槽照留。
- 精确剪点用 `energy.py` 看 20ms 音量条：字和字之间的低谷就是剪点；第二遍开口前留 0.03–0.05 秒。

## 3. 停顿

- 停顿 = 低于 -32dB 的一段（把换气也算进去；-36dB 会把换气当成说话，压不干净）。
- **≤0.4 秒不剪**：每多一刀画面就多一次跳，剪太碎观众会觉得画面一直在跳。
- **>0.4 秒的剪掉**：从停顿中间切开，切出来的剪点按下面「剪点两侧」收，剩约 0.14 秒。`edl.py rebuild --pause-max 0.4`。
- 剪口误顺带空出来的停顿，同样按剪点两侧的规则收。

## 4. 剪点两侧和碎片

- 每个剪点前后的空白（含换气）收掉：段尾声音后留 0.08 秒、段头声音前留 0.06 秒，合计约 0.14 秒。句子中间的自然停顿不动。
- 剪剩不到 0.3 秒的小段直接删。23 秒那下"抽搐"就是两刀之间漏下的 2 帧碎片（0.06 秒），画面是别的时刻，一闪而过。
- **开头第一帧就有声音**：说话之前的时间全部剪掉，0.2、0.3 秒也不留。`cut_takes.py` 自动把第一段切到开口那一帧。
- 这两条都在 `edl.py rebuild` 里，它会打印切了几处长停顿、收掉多少秒、删了哪些碎片；`qa.py` 再从成片上核。

## 5. 片头响指

系列固定片头在素材最前面，结尾手伸到镜头前打响指；正片开头也打响指（可能打了好几次，留最后一次）。`find_snaps.py` 列出音频瞬态并出逐帧拼图，片头里人声多，响指跳变小，加 `--jump 6`。
- **片头出点**：片头响指声之前、手已经挡住大半个镜头的那一帧（`h: "both"`），片头自己的响指声不要。
- **正片入点**：正片最后一次响指声之前约 3 帧、手举在镜头前不动的那一帧（`h: "from"`）。这样只有一声响指，落在切点后 0.1 秒左右。
- 两边都是手挡镜头，硬切就是丝滑转场：这一刀不融合、不叠化、不推拉。
- 片头是单独文件时，先按相同分辨率、帧率、采样率用 concat 滤镜重新编码拼成一个源，再写剪辑表。

## 6. 转写的坑

- **整段转写会吞重复**：Whisper 把「所以我们所以我们」写成一遍，把「能把公…这个…能把兄弟」写成「能把兄弟」，被吞的部分摊进前后的字里，那个字的时长就异常（一个字 0.5–1.6 秒）。所以必须跑 `find_ng.py`：按 ≥75ms 的安静处切成短语，每段单独听写，比较相邻两段（中间夹一段不到 0.6 秒的「这个」「呃」时跨过去比）：后一段以前一段开头，或前一段的尾巴等于后一段的开头，就是重复。
- `find_ng.py` 还会列：单独成段的语气词（「这个」「嗯」，句首正常的「这个」不剪）、每字超过 0.45 秒的拖长字（看它里面有没有藏着别的音节）、语速明显偏慢的字幕行。这些是线索，逐个用 `energy.py` 和单段听写核，核下来是正常停顿或听错的（「出来」听成「吃过来」）不剪。
- 短语听写里会冒出「请不吝点赞订阅」这类幻觉，那是不到 0.2 秒的噪声，忽略。
- 剪完、改完剪辑表，都要重新转写 `cut.mp4` 通读，再对改过的地方跑一次 `find_ng.py`。
