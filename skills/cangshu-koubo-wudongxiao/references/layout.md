# 9:16 版式和上黑边

## 画面

- 成片 1080×1920，原 3:4 画面（1440×1920）缩到 1080×1440 嵌进去，**不拉伸**。上黑边 300px、下黑边 180px，底色 `#0B0B0C`。
- 顶上约 110px（5–10% 高度）是 App 的按钮区，上黑边的内容都放在它下面。
- 素材不是 3:4 时，`make_source.py` 先把画面居中裁成 3:4 的 1440×1920：9:16 竖拍会裁掉上下各约 12%（头顶留空少的素材先问用户），16:9 横拍只剩中间一条（人要在画面正中）。3:4 竖拍效果最好。

## 上黑边放什么

只放四样：系列名、DAY（期数）、分节进度条、本节编号和摘要。上黑边每句都变会和字幕抢注意力，观众不知道看哪；只留一个进度感：讲到哪了、这一节讲什么。

不放：时间、跟着台词变的要点卡、任何每句都在变的东西。整片只在换节时变一次。

| 行 | 内容 | 位置（上黑边内） | 样式 |
|---|---|---|---|
| 1 | 左：系列名；右：DAY 胶囊 | 基线约 146 | 系列名冬青黑体 W3 30px 灰 `#A0A0A0`；DAY 用 DIN Condensed 34px 点缀色字，胶囊底是点缀色 18% 透明 |
| 2 | 分节进度条 | y 190–202 | 每节一段，长短按这一节的时长；讲完的浅灰、当前段点缀色填到当前位置、没讲的深灰；播放头白点带点缀色微光 |
| 3 | 本节编号 + 摘要，**整行居中** | 基线约 274 | 编号 DIN 54px 点缀色；摘要 W6 40px 白 |

换节时：旧的一行 0.18 秒往上淡出，新的 0.15 秒后从下面升上来（0.3 秒）。

## 点缀色

上黑边只用一个低饱和的淡色，用在 DAY、进度条当前段、本节编号上。字幕重点词的亮黄不受影响。

| 名字 | RGB | 说明 |
|---|---|---|
| 鼠尾草绿（默认） | (160, 196, 172) | |
| 雾蓝 | (156, 182, 222) | |
| 冷白灰 | (214, 217, 224) | 最安静 |
| 丁香紫 | (186, 174, 222) | |

## 分节摘要怎么写

- 一节一句，≤10 个字，从讲者这一节的原话里提，**挂一个没解开的问题或一个反常识的判断**：「程序员死得早是好事」「新项目为啥接得少」「先出来的人反而赢」「我离开大厂是因为怕」（举例）。
- 不写「开场」「公司近况」这种栏目名。
- 不写「副业」「躺赚」「月入」这类会被当成收益承诺的词。
- 摘要是 agent 写的屏幕文字，文字自查时有问题就直接改到位。
- 分节按内容切，一般 5–7 节；每节在 `剪辑配置.json` 里写「从哪句字幕开始」（字幕原文），剪辑、变速以后时间自动跟着走。

系列名是每个系列固定的，DAY（期数）每期改；两样都可以留空，留空就不画。
