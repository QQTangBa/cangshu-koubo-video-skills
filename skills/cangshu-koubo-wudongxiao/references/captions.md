# 字幕和消音

## 字幕源怎么写

`$P/字幕源.txt` 一行一条，`#` 开头是注释，`[ ]` 标重点词。
- 字用讲者说的话；只改 ASR 错字和专名（讲者名字、产品名、缩写这类）。改了哪些、拿不准哪些，交付时列出来让用户核。
- 字幕和声音说的一致：口误剪掉时被带掉的字（例：「团队吧」的「吧」），字幕也删。
- 单行 ≤14 字，断在意群处，不断在词中间；不超过 0.35 秒的短行并进相邻行。
- 重点词：结论、数字、反差词、关键名词，一行最多一两个，大约三到五成的行有。

## 敏感词

中文短视频平台对涉钱、涉政的字幕容易限流。默认替换表（只改字幕，声音不动）：

| 说的 | 字幕写 |
|---|---|
| 钱（含谐音） | `$` |
| 金额里的「万」 | `w`（「100 万」→「100w」） |
| 政策 | `Z策` |
| 政府机构名 | 字幕里直接不写这几个字，句子照留 |
| 非点名不可的平台名 | 用谐音或首字母代替 |

`captions.py` 兜底只换「钱」；其余在字幕源里手写好。用户有自己的替换词就补进这张表；不需要替换的账号（比如海外平台）可以整张表不用。

## 样式

- 白色粗字（冬青黑体 W6）+ 深色柔阴影，重点词亮黄 `#FFD23F`；58px（1080 宽），中心在画面 80% 高度处（压在胸口）。
- **出现**：0.18 秒轻弹（0.9→1.0 带一点回弹）+ 0.1 秒淡入。
- **消失**：一帧直接消失，不淡出、不缩、不扭。淡出、扭曲这类消失特效拖泥带水，干扰下一句。

剪点光流融合如果把上一句字幕一起融了，就会出现"扭着淡出的旧字幕"：融合用的"剪点前最后一帧"必须在叠字幕**之前**拷贝（`render.py` 里已经这样做，改渲染代码时别弄回去）。

## 消音

- **不主动消音**。字幕替换（上表）是默认做的；声音消音（"滴"一声）会打断观感，只在用户点头后做。
- 先列：通读字幕时把可能要消音的词（机构名、点名、明显违规词）列出来，每个写清在哪一句、几分几秒、为什么可能要消、不消的风险是什么，问用户。说消哪个才消哪个。
- 做法：被消的词那一段原声静音，换成 1000Hz 正弦「滴」，音量和人声相当（振幅 0.2，约 -17dB），首尾 5ms 淡入淡出。
- 定位：先用转写找到词的大概位置，再用 `energy.py` 看音量条定准起止（词的第一个音节起点前 0.03 秒到最后一个音节结束后 0.05 秒），前后的字不能被盖到。用 `edl.py map` 换成**原片时间**存进 `剪辑配置.json` 的 `bleep`，换剪辑后 `make_source.py` 自动映射。
- 映射后可能偏 0.1 秒左右（词前的空白刚好落在剪点上时）。所以每次 `make_source.py` 之后都看它打印的音量条（被滴盖住的部分标出来），`qa.py` 再听写确认听不到被消的词、前后的字还在；偏了就在当前时间线上重新定位、回写原片时间。
